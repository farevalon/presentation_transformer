Recurrence reads one word at a time. Attention reads them all at once.

An RNN folds everything it has seen into one hidden state and hands it forward, step after step. Information from “France” has to survive four updates before it can help predict “French”, and none of those steps can run in parallel.

Self-attention connects every position to every other position directly. Any two tokens are one hop apart, and the whole sequence is processed with a few large matrix multiplies, which is what made training on GPUs at scale practical.

Text becomes tokens, tokens become vectors

A tokenizer splits text into subword pieces from a fixed vocabulary (GPT‑2’s has 50,257 entries). Each piece maps to an integer ID, and each ID picks out one row of a learned embedding matrix.

That row is the model’s starting point for the token: a vector of dmodel numbers, typically 768 to 12,288 of them. Here each vector is cut to its first 16 values, colored by sign and size.

This tokenizer is a toy that chops long words into fixed-size chunks. Real tokenizers (BPE, WordPiece, SentencePiece) learn their pieces from data, and these embedding values are random stand-ins.

Attention has no sense of order, so position is added in

Self-attention treats its input as a set: shuffle the tokens and the outputs simply shuffle with them. To give the model word order, the original transformer adds a fixed sinusoidal vector to each embedding.

PE(pos, 2i) = sin(pos / 100002i/d)
PE(pos, 2i+1) = cos(pos / 100002i/d)

Low dimensions oscillate fast and high dimensions slowly, like the hands of a clock. The dot product of two encodings depends mostly on how far apart they are, so relative position is easy to read off. Most recent LLMs use rotary embeddings (RoPE), which apply the same idea as a rotation of queries and keys.

Rows are positions 0 to 63, columns are dimensions 0 to 63.

Queries, keys and values: a lookup you can train

Each token is projected three ways. Its query says what it’s looking for, its key says what it offers, and its value is what it hands over if chosen.

A Python dictionary returns the one value whose key matches exactly. Attention scores the query against every key, turns the scores into weights with softmax, and returns a weighted blend of all the values. Because every step is smooth, gradients flow through it and the projections can be learned.

Drag the query. Raise the sharpness and the soft lookup starts to behave like a hard one.

Many heads, each looking for something different

Instead of one attention over full-width vectors, a layer runs h smaller heads in parallel, each with its own WQ, WK and WV of width dmodel / h. Their outputs are concatenated and mixed back together by WO.

Trained heads often specialize. Some track the previous token, some link verbs to their subjects, some spread out to gather broad context. These patterns are hand-built to show the idea; real heads are messier and harder to name.

The transformer block

A model is a stack of identical blocks. In each one, tokens first exchange information through attention, then every token is processed on its own by a small MLP. Residual connections and normalization keep a deep stack trainable.

The catch: attention grows with the square of the length

The score matrix has one entry for every pair of tokens. Double the context and that matrix gets four times bigger, while the rest of the block only doubles.

Real systems work around this. FlashAttention computes attention in tiles without ever storing the full matrix, the KV cache avoids recomputing keys and values during generation, and grouped-query attention, sliding windows and sparse patterns cut the cost further.

Generating text, one token at a time

A decoder outputs a probability for every token in its vocabulary at the next position. Pick one, append it, run the model again. That loop is all generation is.

Temperature divides the logits before softmax: below 1 sharpens the distribution toward the top choice, above 1 flattens it. Top-k keeps only the k most likely tokens and renormalizes. Draw some samples and watch how often each word comes up.

What to take away

  • Attention is a soft, learnable lookup: queries score keys, softmax turns scores into weights, and values are blended by those weights.
  • Every token reaches every other in one step, so training parallelizes well, at the price of cost that grows with the square of the length.
  • Order comes from positional information, and a causal mask turns the same machinery into a text generator.
  • A model is a stack of attention and MLP blocks joined by a residual stream.
